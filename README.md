Street Fighter Zero 3 Saturn - English Translation



This patch turns the Japanese Sega Saturn release of Street Fighter Zero 3 into an English version that looks and reads like an official Western release of Street Fighter Alpha 3. It uses the official English script and graphics of the PSP version, Street Fighter Alpha 3 MAX, and of the NAOMI arcade version, with new translations for everything that never existed in English. The Unlocked Characters patch also makes Shin Gouki and Final Vega selectable from the start.


FILES :


Street Fighter Zero 3 - English Translation 1.0.xdelta is the standard version, to use with Delta Patcher or xdelta UI.

Street Fighter Zero 3 - English Translation 1.0.ssp is the standard version, to use with Sega Saturn Patcher.

Street Fighter Zero 3 - English Translation & Unlocked Characters 1.0.xdelta is the version with unlocked characters, to use with Delta Patcher or xdelta UI.





PATCHING INSTRUCTIONS :


XDelta patch :


The patch applies to Street Fighter Zero 3 (Japan) (Track 1).bin from the original Redump disc image.

The original track must have the MD5 checksum E9088A83E44B0ED2500597328A1EB391.

In Delta Patcher, open the settings and enable Checksum validation and Backup original file.

Select the original track as Original file.

Select the xdelta file as XDelta patch.

Click Apply patch.

The patched track must have the MD5 checksum 7BB355535369471B8E72D98E07EEB65F for the standard version, or 1A5064B910D75FC9D55EF7FBBF70D19F for the Unlocked Characters version.

Keep the cue file and Track 2 as they are.


SSP patch:


Open the original Japanese disc image in Sega Saturn Patcher.
Add the file Street Fighter Zero 3 - English Translation 1.0.ssp.
Build the patched disc image.


Notes:


Never apply a patch to a disc image that is already patched.

The 4MB Extended RAM Cartridge is required, like for the original game.

WHAT'S CHANGED :


- Character names follow the Japanese version.

- Gouki is used instead of Akuma, and Nash instead of Charlie.

- Shin Gouki is shown as S.Gouki under the life bar, VS screen, select screen and win screen.

- The Western title Street Fighter Alpha 3 is used everywhere, on the title screen, the intro logos with the A L P H A letters flying in, the announcer voice, the main menu, 
  the background stone logo, the loading screens, the banners, the credits and the save messages.

- Z-ISM becomes A-ISM everywhere, using the official PSP graphics.

- In-fight messages read Alpha Counter, Custom Combo Finish, Alpha Combo and Alpha Cancel.

- Arcade mode rivals and boss dialogues, character introductions, endings and generic win quotes use the official English script of the PSP version, with a few typos fixed.

- All win quotes against each opponent, which only ever existed in Japanese, are translated to English. That makes 1089 quotes, each character having a unique quote against every opponent.

- Save, load and Entry mode menus, World Tour ISM PLUS descriptions and pre-fight tips, and the save memory and RAM cartridge warning screens are translated.

- Stage names on the NEXT STAGE screen are written in English, for example Genbu Plain or Hotel Masters.

- All text uses the green gradient Naomi/PSP font.



UNLOCKED CHARACTERS PATCH :

- Shin Gouki and Final Vega are available right away, without finishing World Tour.

- On the character select screen, press START on Gouki to switch to Shin Gouki, and again to switch back.
  Press START on Vega to turn Final Vega on or off.

- A sound confirms the change, then pick the character with any attack button.
  This works in Arcade, VS and Training, the only modes where the game allows Final Vega.
